# 스낵게임 웹 이식 실험

기존 Flutter 화면을 참고해 브라우저 기본 스크롤, HTML/CSS와 Canvas 2D로 옮긴 웹 버전이다. 14개 게임 코드를 유지하며 현재 다섯 게임만 홈과 기록 화면에 표시한다.

저장소 루트에서 `python experiments/canvas-full/serve.py`를 실행한 뒤 `http://localhost:8768/`을 연다. 서버는 이 폴더와 화면에 필요한 폰트·효과음·아이콘만 제공한다. `build/web/assets/assets/fonts`에 기존 폰트 서브셋이 있으면 그것을 사용하고, 없으면 원본 폰트를 사용한다.

`node experiments/canvas-full/scoring.test.cjs`로 세 게임의 점수 계산 경계값을 확인할 수 있다.

기록은 `snack.canvas.v1.` 접두사의 별도 브라우저 저장소에 저장한다. 기존 Flutter 사이트와 같은 출처에서 처음 실행하면 기존 Flutter 설정과 기록을 읽어 별도 키로 복사하며 원본을 수정하지 않는다. 다른 출처에서는 브라우저 보안 정책 때문에 기존 기록을 읽을 수 없다.

시작 시 `version.json`을 네트워크에서 비동기로 확인한다. 새 버전이 있으면 안내하고 서비스워커 업데이트를 요청하지만 진행 중인 게임을 강제로 새로고침하지 않는다. 네트워크가 없거나 확인이 실패하면 알림 없이 캐시된 버전으로 실행한다. 배포 빌드는 클라이언트와 서비스워커에 동일한 커밋 버전을 기록한다.

게임의 기본 시작·종료, 기록·언어·공유와 일부 점수 경로를 데스크톱에서 확인했다. 모든 성공·실패 분기, 화면 모양의 완전한 일치, iOS 실기 성능과 진동·공유·홈 화면 설치는 별도 검증이 필요하다. 진동은 브라우저의 지원 여부에 따른다. 오프라인 서비스 워커는 HTTPS 또는 localhost에서만 작동한다.
