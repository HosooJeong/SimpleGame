# Canvas 비교판

기존 Flutter 배포와 분리된 홈 화면 및 타이밍 스톱 비교용 프로토타입이다.
홈 스크롤은 브라우저 기본 스크롤이고 공과 트랙은 Canvas 2D로 그린다.

저장소 루트에서 다음 명령으로 실행한다.

```sh
python -m http.server 8767 --bind 0.0.0.0
```

브라우저에서 `/experiments/canvas-prototype/`을 연다.
이 명령은 저장소 전체를 제공하므로 신뢰할 수 있는 네트워크에서만 사용한다.
다른 게임, 사운드, 공유, 설정과 통계 화면은 구현하지 않았다.
최고 점수는 이 비교판의 브라우저 저장소에만 따로 저장된다.
실제 기기의 프레임 성능 및 60fps 유지는 아직 검증하지 않았다.
